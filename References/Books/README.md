# Books and reference material

This directory is an index of reference books supplied for the SAC01 Software Architecture course. It does not redistribute the books themselves.

> **Copyright:** The repository `acuscorp/SoftwareArchitecture` is public. Full-text PDFs/EPUBs are not committed here unless their license or the rights holder explicitly permit public redistribution. Use the publisher, author, or other authorized source for access.

## Edition and availability gaps

The workspace includes *Software Architecture in Practice*, 3rd ed., while the current route cites the 4th ed. The route also cites *Designing Software Architectures*, 2nd ed., *Object-Oriented Software Engineering*, and *Just Enough Software Architecture*; their corresponding files were not among the accessible PDF attachments at the time this index was prepared. Confirm exact editions and authorized access before assigning readings.
