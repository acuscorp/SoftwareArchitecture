## Edition and availability gaps

The workspace includes *Software Architecture in Practice*, 3rd ed., and this is the edition mapped to CL01.04.01. The route cites other books whose corresponding files were not among the accessible PDF attachments when this index was prepared, including *Designing Software Architectures*, 2nd ed., *Object-Oriented Software Engineering*, and *Just Enough Software Architecture*. Confirm exact editions and authorized access before assigning readings for those classes.

Do not infer that a book is available to students merely because its title appears in the route or this index.

## Maintenance rules

1. Keep bibliographic metadata and course-to-book mappings here.
2. Do not commit copyrighted full-text books to this public repository without explicit redistribution permission.
3. Prefer official publisher/author links or openly licensed copies.
4. Record the exact edition used by each class plan; do not silently substitute editions.
5. When a class changes its source mapping, update that class and this index consistently; review unrelated classes separately.
