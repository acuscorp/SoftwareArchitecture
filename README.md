## Criterio de publicación

Este repositorio contiene únicamente la ruta curricular, el estado de aprobación/revisión de la ruta y los planes de clase asociados.

La aprobación de la estructura curricular no implica que todos los planes de clase estén aprobados o listos para impartirse. Cada clase debe validarse antes de su impartición.

Los nombres de archivo se mantienen estables; el historial de cambios se gestiona mediante Git.
