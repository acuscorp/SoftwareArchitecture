# Software Architecture — SAC01

Repositorio del curso de Arquitectura de Software. La organización por carpetas reúne el currículo, las clases, la evaluación, el progreso y las decisiones de validación.

## Documentos canónicos

- [Matriz maestra de competencias](Curriculum/MATRIZ_COMPETENCIAS.md): fuente maestra para **Software Architecture** y **AI Solution Architecture**. Su estado permanece **DRAFT — PENDING_REVIEW**; ser la fuente maestra no implica que esté aprobada.
- [Ruta curricular](Curriculum/LEARNING_PATH.md): mapa aprobado para planificación, con validación obligatoria de cada clase antes de impartirla.
- [Dictamen curricular](Validation/ROUTE_REVIEW_AND_DECISION.md): decisión sobre la estructura de la ruta y sus condiciones de entrega.
- [Plan CL01.02.02](Classes/M01/CL01.02.02_PLAN.md) y [plan CL01.04.01](Classes/M01/CL01.04.01_PLAN.md): ambos siguen como borradores para revisión.
- [Trazabilidad de evidencias](Assessment/REGISTRO_TRAZABILIDAD_EVIDENCIAS.md) y [rúbricas](Assessment/RUBRICAS_EVIDENCIAS_RUTA.md): conservan su estado de revisión declarado en cada archivo.
- [Estado del curso](Progress/COURSE_STATE.md): registra el punto de partida y el progreso individual.

## Estados y gobierno

La matriz de competencias es la fuente maestra para definir competencias. La ruta, los planes de clase, la trazabilidad y las rúbricas mantienen sus propios estados; ningún borrador se vuelve aprobado por estar enlazado aquí. La aprobación de la estructura curricular no aprueba automáticamente los planes, las lecturas ni las evaluaciones.

Git conserva el historial de cambios. Cada documento tiene una ruta canónica estable; las carpetas usan nombres descriptivos sin prefijos numéricos.
